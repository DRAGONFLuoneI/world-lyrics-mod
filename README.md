# World Lyrics — Minecraft 1.20.1 (Forge)

Текст играющей песни прямо в мире Minecraft: караоке-заливка по буквам, анимации, частицы и эффекты камеры. Мод только клиентский: на сервер ставить не нужно, с ним можно заходить на любые серверы.

## Как это работает

Трек, позицию и строки мод берёт у программы **Lyrics Overlay 2.1+**. Программа определяет музыку в Windows и находит синхронизированный текст. Мод подключается к ней по локальному мосту `127.0.0.1:47811`.

1. Запустите Lyrics Overlay. Проверьте, что мост включён: «Приложение → Интеграции → Мост для Minecraft».
2. Положите `worldlyrics-1.20.1-1.0.0.jar` в `.minecraft\mods`. Нужен Forge 47.x для 1.20.1.
3. Включите музыку и зайдите в мир.

## Сборка .jar

Запустите **`build.bat`**. Если Java нет, скрипт поставит JDK 17. Первая сборка скачивает Minecraft и Forge и занимает 5–15 минут, готовый `.jar` появится рядом со скриптом.

Можно собрать и через GitHub: залейте папку в репозиторий, и GitHub Actions соберёт `.jar` сам. Файл появится во вкладке Actions в разделе Artifacts.

## Режимы

| Режим | Что происходит |
|---|---|
| **Перед камерой** | Панель из нескольких строк парит перед глазами и с пружинной инерцией догоняет взгляд. |
| **Разбросано в мире** | Каждая новая строка появляется в новом месте в поле зрения: над землёй, в прямой видимости. Старые строки висят в мире и растворяются. |
| **Закреплено на месте** | Панель висит в точке мира, как голограмма. Клавиша **H** переносит её к вам. |
| **Только HUD** | Строки показываются только на экране, как субтитры. |

## Эффекты

- **Караоке:** заливка по буквам с мягкой границей, режим «вся строка» или без подсветки. Можно включить радужную заливку.
- **Появление строки:** проявление, пружинка, волна по буквам, печатная машинка или подъём снизу.
- **Исчезновение строки:** растворение, улетает вверх, сжатие или рассыпается по буквам.
- **Движение:** пульс текущей строки, покачивание, наклон, желейная прокрутка строк.
- **Частицы на новой строке:** ноты, энд-стержень, руны, лепестки вишни, искры, снежинки, огни душ, фейерверк. Отдельно можно включить шлейф вокруг текущей строки.
- **Камера и экран:** «дыхание» поля зрения (FOV), вспышка по краям экрана, лёгкая тряска.
- **Титр трека:** название и исполнитель крупно появляются, когда начинается новая песня, в мире или на экране.
- **Оформление текста:** обводка, свечение, тень, подложка, «видно сквозь блоки», «всегда ярко».

## Настройки

Всего 89 настроек в 6 вкладках: Общее, Текст, Место, Анимация, Эффекты, Связь. Открыть их можно:
- клавишей **O**;
- в «Моды → World Lyrics → Настройки».

Всё применяется сразу, мир за меню не ставится на паузу, поэтому результат виден в реальном времени. Наведите курсор на название настройки, чтобы увидеть подсказку. Клик по цветному квадратику перебирает палитру (ПКМ — назад), прозрачность при этом сохраняется. Файл настроек: `config/worldlyrics-client.toml`.

## Клавиши

| Действие | Клавиша |
|---|---|
| Показать / скрыть | **K** |
| Настройки | **O** |
| Текст раньше / позже | **]** / **[** |
| Закрепить здесь | **H** |
| Сменить режим, перезагрузить текст | не назначены |

Все клавиши переназначаются в «Настройки → Управление → World Lyrics». Сдвиг из игры сохраняется в Lyrics Overlay для этого трека.
